FLOOR CANDIDATES

Every one-square floor tile in the repo, laid four by four inside a corner of the game's real perimeter wall. The wall is the point: a floor from the same kit as the wall shares its palette exactly, and the join between them disappears.

RUINS TILES, RECOLOURED

The ruins kit has the only floor tiles in the repo with a pattern on them, and the only thing wrong with them is that they are the wall's exact colour. Both kits are flat untextured colour, so that is a colour assignment — the same one that already brings the dungeon arches into the ruins wall run. Same tile, same wall, four stones.

FLOOR, PER FLOOR TYPE

Each patch is six squares by six, laid with the same weights, the same hash and the same quarter-turns the renderer uses — so this is the floor the game will actually build for a room of that type, not an impression of it. Rendered without the pixelation pass.

PROP VARIANTS

Every model a prop type may be built from, at the height and footprint it is configured with, standing against one square of wall for scale. A type's variants have to read as the same noun — the DM is told the type name and writes it into the narration.
